## Dev Notifier: know when Jira or GitHub needs you

<a href="https://github.com/SteveZouWonder/dev-notifier"><img align="right" width="128" src="https://raw.githubusercontent.com/SteveZouWonder/dev-notifier/main/assets/app-icon.png" alt="Dev Notifier app icon"></a>

A tray app for macOS and Windows. Every few minutes it checks Jira, GitHub and PagerDuty for things that involve you — review requests, mentions, comments on your tickets, CI on your open PRs — and shows a desktop notification you can click straight through.

**[Download →](https://github.com/SteveZouWonder/dev-notifier/releases)** · [Source](https://github.com/SteveZouWonder/dev-notifier) · [Tutorial](https://github.com/SteveZouWonder/dev-notifier/blob/main/TUTORIAL.md)
